# אי ודאות

ריפו ייעודי וקנוני לתחום אי־ודאות במתמטיקה לחטיבת הביניים.

## מקור האמת

`yanivmizrachiy/i-vadaut` הוא מקור האמת היחיד והפעיל.

הריפו הישן `yanivmizrachiy/i-vadaut-ai-studio` הוגדר Legacy/Read-Only ואינו מיועד לפיתוח חדש. חומר שהועבר ממנו נשמר תחת `ai-studio/` עד להשלמת parity ואימות קבצים בינאריים.
